# 🧠 Multi-Stage RAG Mental Health Support Chatbot

An end-to-end **Retrieval-Augmented Generation (RAG)** chatbot designed to provide empathetic and context-aware support for mental health topics such as anxiety, stress, depression, and coping strategies.

The system combines **Language Detection**, **Emotion Classification**, **Intent Routing**, and **Semantic Retrieval** to generate relevant and personalized responses.

---

## ✨ Features

* 🌍 Multilingual language detection
* 😊 Emotion-aware response generation
* 🎯 Intent classification and routing
* 📚 Retrieval-Augmented Generation (RAG)
* 🔎 Semantic search with Qdrant
* 🤖 Groq Llama-powered response generation
* ⚡ FastAPI backend
* 💬 Streamlit chat interface

---

## 🧠 Models Used

| Component              | Model              |
| ---------------------- | ------------------ |
| Language Detection     | TF-IDF + LinearSVC |
| Emotion Classification | DeBERTa-v3 Base    |
| Intent Classification  | Groq Llama         |
| Embeddings             | BAAI/bge-m3        |
| Vector Database        | Qdrant             |

### Design Choices

* **LinearSVC** provides fast and accurate language detection for short texts.
* **DeBERTa-v3** captures emotional context while remaining computationally efficient.
* **BAAI/bge-m3** offers strong multilingual retrieval performance and long-context support.
* Patient **contexts** are embedded instead of therapist responses, improving retrieval quality by matching similar user situations.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/mental-health-rag-chatbot.git
cd mental-health-rag-chatbot
```

### Create Virtual Environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Create a `.env` file:

```bash
cp .env.example .env
```

Add your credentials:

```env
GROQ_API_KEY=your_api_key
QDRANT_URL=your_qdrant_url
QDRANT_API_KEY=your_qdrant_api_key
```

---

## 📚 Data Ingestion

Initialize the Qdrant collection and ingest the dataset:

```bash
python -c "from src.rag_pipeline import RAGPipeline; r = RAGPipeline(); r.ingest_data_from_csv('mental_health_dataset.csv')"
```
