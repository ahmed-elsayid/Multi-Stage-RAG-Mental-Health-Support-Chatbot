# 🧠 Multi-Stage RAG Mental Health Support Chatbot

An end-to-end **Retrieval-Augmented Generation (RAG)** chatbot designed to provide empathetic and context-aware support for mental health topics such as anxiety, stress, depression, and coping strategies.

The system combines **Language Detection**, **Emotion Classification**, **Intent Routing**, and **Semantic Retrieval** to generate relevant and personalized responses.

---

## ✨ Features

* 🌍 Multilingual language detection
* 😊 Emotion-aware response generation
* 🎯 Intent classification and routing
* 📚 Retrieval-Augmented Generation (RAG)
* 🔎 Semantic search with Qdrant
* 🤖 Groq Llama-powered response generation
* ⚡ FastAPI backend
* 💬 Streamlit chat interface

---

## 🧠 Models Used

| Component              | Model              |
| ---------------------- | ------------------ |
| Language Detection     | TF-IDF + LinearSVC |
| Emotion Classification | DeBERTa-v3 Base    |
| Intent Classification  | Groq Llama         |
| Embeddings             | BAAI/bge-m3        |
| Vector Database        | Qdrant             |

### Design Choices

* **LinearSVC** provides fast and accurate language detection for short texts.
* **DeBERTa-v3** captures emotional context while remaining computationally efficient.
* **BAAI/bge-m3** offers strong multilingual retrieval performance and long-context support.
* Patient **contexts** are embedded instead of therapist responses, improving retrieval quality by matching similar user situations.

## 📗 Module 4 — Q&A RAG Pipeline

**Notebook:** `notebooks/04_QA_RAG.ipynb`
**Runtime script:** `src/rag_runtime.py`
**API endpoint:** `POST /chat`

### Architecture

Module 4 is split into two parts:

| Part | File | When it runs |
|---|---|---|
| Ingestion (one-time) | `notebooks/04_QA_RAG.ipynb` | Run once to build the knowledge base |
| Retrieval (runtime) | `src/rag_runtime.py` | Runs on every user question |

### What the notebook does (run once, already done)

1. Loads the Mental Health Counseling Conversations dataset (3512 rows)
2. Cleans data — drops 4 empty responses → 3508 rows
3. Combines `Context + Response` into a single text chunk per row
4. Embeds all 3508 chunks using `all-MiniLM-L6-v2` (384-dimensional vectors)
5. Creates Qdrant Cloud collection `mental_health_chunks`
6. Uploads all vectors with their text payloads to Qdrant Cloud

The knowledge base is already live. The notebook does not need to be re-run.

### What the runtime script does (on every question)

1. Accepts a user question and an optional emotion label from Module 2
2. Checks for crisis language — returns a direct safety message if detected
3. Embeds the question using the same `all-MiniLM-L6-v2` model
4. Queries Qdrant Cloud for the top-3 most similar counseling chunks
5. Builds a prompt from the retrieved `context` and `response`
6. Calls Groq API (`openai/gpt-oss-20b`) to generate the final answer

### Module 4 Models and Tools

| Component | Choice |
|---|---|
| Dataset | Mental Health Counseling Conversations (HuggingFace) |
| Embeddings | `all-MiniLM-L6-v2` (SentenceTransformers) |
| Vector database | Qdrant Cloud |
| Collection name | `mental_health_chunks` |
| Similarity metric | Cosine |
| LLM | Groq `openai/gpt-oss-20b` |
